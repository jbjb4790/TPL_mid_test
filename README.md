# Young's Physics 온라인 시험 사이트

이 저장소는 GitHub Pages로 공개되는 학생용 시험 화면입니다.

## 업로드 방법

1. 이 ZIP 파일을 압축 해제합니다.
2. 압축을 푼 폴더 안의 모든 항목을 GitHub 저장소 최상위에 업로드합니다.
   - `docs/`
   - `README.md`
   - `.gitignore`
3. GitHub Pages 설정에서 배포 소스를 `main` 브랜치의 `/docs` 폴더로 지정합니다.
4. Google Apps Script 웹 앱 URL을 받은 뒤 `docs/config.js`의 `appsScriptUrl`에 붙여 넣습니다.

## 응시자 정보

학생은 `학교/학년`과 `이름`만 입력합니다. 별도의 고유 ID 입력란은 없습니다.
서버는 시험 ID, 학교/학년, 이름의 조합으로 중복 응시와 이어보기를 관리합니다.
같은 학교·학년에 동명이인이 있는 경우에는 이름 뒤에 반 또는 번호를 함께 입력하도록 안내해 주세요.

## 중요

`private-admin/` 폴더와 `GoogleAppsScript_Code.gs`는 이 GitHub 업로드용 ZIP에 포함되어 있지 않습니다.
정답과 채점 코드는 Google Apps Script에만 넣어야 합니다.


## 시험 시간 설정

현재 공개 파일과 Apps Script는 **시작/종료 시각 제한 없이** 운영되도록 설정되어 있습니다.
학생은 원하는 시간에 시험을 시작할 수 있고, 시작한 순간부터 **60분 이내**에 제출해야 합니다.
브라우저 화면의 타이머도 60분으로 표시되며, 서버에서도 60분 이후 제출을 막습니다.

## 학생 점수 표시

학생이 최종 제출하면 Apps Script 서버에서 즉시 채점한 뒤 화면에 100점 만점 점수를 보여줍니다.

- 문항당 배점: `100 / 문항 수`
- 정답: 배점만큼 가산
- 미응답: 0점
- 오답: 배점의 1/4만큼 감점
- 총점 하한 없음: 모든 문항을 틀리면 -25점이 될 수 있음

정답은 GitHub 파일에 들어 있지 않고, `private-admin/GoogleAppsScript_Code.gs`에만 있습니다.

## 제출 후 오답 다시 보기

학생이 최종 제출하면 결과 화면에서 오답/미응답 문항을 다시 확인할 수 있습니다.
각 문항에는 다음 정보가 표시됩니다.

- 문항 번호
- 본인이 선택한 답안
- 실제 정답
- 문제 이미지

정답 정보는 GitHub 공개 파일에 들어 있지 않으며, 제출 후 Apps Script 서버가 해당 학생의 오답/미응답 문항 정보만 반환합니다.
같은 시험에서 같은 학교/학년과 이름으로 다시 접속하면 저장된 결과와 오답 확인 화면을 다시 표시합니다.
